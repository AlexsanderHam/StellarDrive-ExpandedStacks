# Expanded Stacks

A minimalist mod for **StellarDrive** that expands the maximum stack size of all items.

## 🌟 Features

- Increases the maximum stack size for every item in the game to **255**.
- Lightweight and performance-friendly, patched cleanly via Harmony.

## 📥 Installation

This mod can be installed and managed using [StellarModManager](https://github.com/jollyname/StellarModManager). Simply launch the manager, find **Expanded Stacks** in the list, and click install!
